# Dataset

Built by `scripts/build_hotpot_subset.py` from HotpotQA distractor validation via Hugging Face `datasets`.

- Questions: `questions.json` (40 items)
- Corpus: `corpus/` (100 docs = supporting + distractors)
- Metadata: `dataset_meta.json`

See `dataset_meta.json` for filtering logic suitable for the paper's dataset section.
